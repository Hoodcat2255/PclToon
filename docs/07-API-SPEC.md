# 07. API Spec

## 1. 개요

PclToon은 **자체 API 서버가 없는 순수 클라이언트 사이드 SPA**이다. 모든 데이터는 pCloud Public API를 브라우저에서 직접 호출하여 획득한다.

| 항목 | 값 |
|------|-----|
| 자체 백엔드 | 없음 |
| 외부 API | pCloud Public API (`api.pcloud.com`) |
| 인증 방식 | 없음 (공개 링크 코드만 사용) |
| API 클라이언트 | `src/lib/pcloud.js` |
| HTTP 클라이언트 | 브라우저 네이티브 `fetch` |
| 실제 HTTP 호출 엔드포인트 수 | 2개 (`showpublink`, `getpublinkdownload`) |

## 2. pCloud API 엔드포인트

### 2.1 `showpublink` — 공개 링크 메타데이터 조회

공유 링크의 메타데이터(폴더 구조, 파일 목록)를 조회한다.

| 항목 | 값 |
|------|-----|
| **URL** | `GET https://api.pcloud.com/showpublink` |
| **메서드** | GET |
| **인증** | 불필요 |
| **CORS** | 허용됨 (브라우저 직접 호출 가능) |

**요청 파라미터:**

| 파라미터 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| `code` | `string` | Y | pCloud 공유 링크 코드 (영숫자) |

**요청 예시:**

```
GET https://api.pcloud.com/showpublink?code=XYZabc123
```

**성공 응답 구조:**

```json
{
  "result": 0,
  "metadata": {
    "name": "폴더명",
    "isfolder": true,
    "folderid": 12345678,
    "contents": [
      {
        "name": "Episode 01",
        "isfolder": true,
        "folderid": 23456789,
        "contents": [
          {
            "name": "001.jpg",
            "isfolder": false,
            "fileid": 34567890
          }
        ]
      },
      {
        "name": "cover.png",
        "isfolder": false,
        "fileid": 45678901
      }
    ]
  }
}
```

**응답 필드 (프로젝트에서 사용하는 필드):**

| 필드 | 타입 | 설명 |
|------|------|------|
| `metadata.name` | `string` | 루트 폴더/파일 이름 |
| `metadata.contents` | `array` | 하위 항목 배열 |
| `metadata.contents[].name` | `string` | 항목 이름 |
| `metadata.contents[].isfolder` | `boolean` | 폴더 여부 |
| `metadata.contents[].fileid` | `number` | 파일 ID (파일인 경우) |
| `metadata.contents[].folderid` | `number` | 폴더 ID (폴더인 경우) |
| `metadata.contents[].contents` | `array` | 하위 폴더의 내용 (재귀 구조) |
| `error` | `string` | 에러 메시지 (에러 시에만 존재) |

**에러 응답 구조:**

```json
{
  "result": 2000,
  "error": "Some error message"
}
```

**프로젝트 내 호출 위치:**

- `src/lib/pcloud.js` > `fetchPublicLink(code)`
- `src/routes/+page.svelte` > `handleLinkSubmit(url)` 에서 호출

**특이사항:**

- 응답에 전체 폴더 트리가 재귀적으로 포함된다. 한 번의 API 호출로 모든 하위 폴더/파일 정보를 획득한다.
- 이후 폴더 탐색 시 추가 API 호출 없이 메모리 내 데이터(`folder.contents`)를 직접 참조한다.

### 2.2 `getpublinkdownload` — 공개 파일 다운로드 URL 획득

공유 링크 내 특정 파일의 임시 다운로드 URL을 획득한다.

| 항목 | 값 |
|------|-----|
| **URL** | `GET https://api.pcloud.com/getpublinkdownload` |
| **메서드** | GET |
| **인증** | 불필요 |
| **CORS** | 허용됨 |
| **referrerPolicy** | `no-referrer` (fetch 옵션으로 명시 설정) |

**요청 파라미터:**

| 파라미터 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| `code` | `string` | Y | pCloud 공유 링크 코드 |
| `fileid` | `number` | Y | 다운로드할 파일의 ID |

**요청 예시:**

```
GET https://api.pcloud.com/getpublinkdownload?code=XYZabc123&fileid=34567890
```

**Fetch 옵션:**

```javascript
{ referrerPolicy: 'no-referrer' }
```

> `no-referrer` 정책은 pCloud CDN의 레퍼러 기반 핫링크 차단을 우회하기 위한 설정이다.

**성공 응답 구조:**

```json
{
  "result": 0,
  "hosts": [
    "edef2.pcloud.com"
  ],
  "path": "/cBZabcDEFxyz/Episode%2001/001.jpg"
}
```

**응답 필드 (프로젝트에서 사용하는 필드):**

| 필드 | 타입 | 설명 |
|------|------|------|
| `hosts` | `string[]` | 다운로드 가능한 호스트 목록 |
| `path` | `string` | 파일 경로 |
| `error` | `string` | 에러 메시지 (에러 시에만 존재) |

**다운로드 URL 조립:**

```
https://{hosts[0]}{path}
→ https://edef2.pcloud.com/cBZabcDEFxyz/Episode%2001/001.jpg
```

**에러 응답 구조:**

```json
{
  "result": 2000,
  "error": "Some error message"
}
```

**프로젝트 내 호출 위치:**

- `src/lib/pcloud.js` > `getImageUrl(code, fileid)`
- `src/lib/components/ImageViewer.svelte` > `onMount` 에서 `Promise.all`로 병렬 호출

**특이사항:**

- `hosts` 배열에서 항상 첫 번째 호스트(`hosts[0]`)만 사용한다.
- 반환되는 URL은 임시 URL이며, 유효 기간이 있다 (pCloud 정책에 따름).

## 3. 클라이언트 API 함수 (`src/lib/pcloud.js`)

### 3.1 `extractCode(url: string): string`

pCloud 공유 URL에서 공유 코드를 추출하는 순수 함수이다.

| 항목 | 값 |
|------|-----|
| HTTP 호출 | 없음 (순수 함수) |
| 반환값 | 추출된 코드 문자열, 패턴 불일치 시 입력값 그대로 반환 |
| 호출 위치 | `+page.svelte` > `handleLinkSubmit()` |

### 3.2 `fetchPublicLink(code: string): Promise<object>`

`showpublink` API를 호출하여 공유 링크 메타데이터를 반환한다.

| 항목 | 값 |
|------|-----|
| HTTP 호출 | `GET https://api.pcloud.com/showpublink?code={code}` |
| 반환값 | API 응답 전체 객체 |
| 에러 | `data.error` 존재 시 `throw new Error(data.error)` |
| 호출 위치 | `+page.svelte` > `handleLinkSubmit()` |

### 3.3 `naturalSort(a: object, b: object): number`

`name` 프로퍼티를 기준으로 자연 정렬 비교하는 함수이다.

| 항목 | 값 |
|------|-----|
| HTTP 호출 | 없음 (순수 함수) |
| 정렬 방식 | `localeCompare(name, undefined, { numeric: true, sensitivity: 'base' })` |
| 용도 | `1화, 2화, 10화` 순서 보장 |
| 호출 위치 | `pcloud.js` 내부의 `processContents()`에서 사용 |

### 3.4 `isImageFile(filename: string): boolean`

파일명의 확장자로 이미지 파일 여부를 판별한다.

| 항목 | 값 |
|------|-----|
| HTTP 호출 | 없음 (순수 함수) |
| 지원 확장자 | `jpg`, `jpeg`, `png`, `gif`, `webp`, `bmp` |
| 호출 위치 | `pcloud.js` 내부의 `processContents()`에서 사용 |

### 3.5 `processContents(metadata: object): { folders: array, images: array }`

API 응답 메타데이터에서 폴더와 이미지를 분리하고 정렬하여 반환한다.

| 항목 | 값 |
|------|-----|
| HTTP 호출 | 없음 (순수 함수) |
| 입력 | `{ metadata: { contents: [...] } }` 구조의 객체 |
| 반환값 | `{ folders: [...], images: [...] }` (각각 정렬 완료) |
| 로직 | `isfolder` 기준 분리 → `isImageFile` 필터 → `naturalSort` 정렬 |

### 3.6 `getFileLink(code: string, fileid: number): string`

`getpublinkdownload` API의 요청 URL을 생성하는 순수 함수이다.

| 항목 | 값 |
|------|-----|
| HTTP 호출 | 없음 (URL 문자열만 반환) |
| 반환값 | `https://api.pcloud.com/getpublinkdownload?code={code}&fileid={fileid}` |
| 호출 위치 | `pcloud.js` 내부의 `getImageUrl()`에서 사용 |

### 3.7 `getImageUrl(code: string, fileid: number): Promise<string>`

`getpublinkdownload` API를 호출하여 이미지의 실제 다운로드 URL을 반환한다.

| 항목 | 값 |
|------|-----|
| HTTP 호출 | `GET https://api.pcloud.com/getpublinkdownload?code={code}&fileid={fileid}` |
| fetch 옵션 | `{ referrerPolicy: 'no-referrer' }` |
| 반환값 | `https://{hosts[0]}{path}` 형태의 다운로드 URL |
| 에러 | `data.error` 존재 시 `throw new Error(data.error)` |
| 호출 위치 | `ImageViewer.svelte` > `onMount`에서 `Promise.all`로 병렬 호출 |

## 4. URL 파싱 패턴

`extractCode()` 함수가 지원하는 URL 패턴 3가지 (순서대로 시도):

| 순서 | 정규식 | 매칭 대상 | 입력 예시 |
|------|--------|-----------|-----------|
| 1 | `code=([a-zA-Z0-9]+)` | 쿼리 파라미터의 `code` 값 | `https://e.pcloud.link/publink/show?code=XYZabc123` |
| 2 | `publink/show\?code=([a-zA-Z0-9]+)` | publink 경로 내 `code` 값 | `https://e.pcloud.link/publink/show?code=XYZabc123` |
| 3 | `/([a-zA-Z0-9]+)$` | URL 마지막 경로 세그먼트 | `https://e.pcloud.link/XYZabc123` |
| 폴백 | — | 입력값 전체를 코드로 사용 | `XYZabc123` (코드 직접 입력) |

**패턴 매칭 동작:**

- 패턴 1과 2는 동일한 URL에 대해 모두 매칭될 수 있으나, 배열 순서상 패턴 1이 먼저 매칭되어 반환된다.
- 패턴 3은 URL 끝의 경로 세그먼트를 추출하므로, 단축 URL 형태를 지원한다.
- 모든 패턴이 실패하면 입력 문자열을 그대로 코드로 반환한다 (사용자가 코드를 직접 입력한 경우).

## 6. 에러 처리 패턴

### 6.1 API 레벨 에러 처리

두 API 호출 함수(`fetchPublicLink`, `getImageUrl`) 모두 동일한 패턴을 사용한다:

```javascript
const data = await response.json();
if (data.error) {
    throw new Error(data.error);
}
```

pCloud API는 HTTP 200을 반환하면서 응답 본문에 에러를 포함하는 방식을 사용한다.

| 에러 상황 | `result` 코드 | `error` 메시지 예시 |
|-----------|---------------|---------------------|
| 유효하지 않은 코드 | 7003 | `"Invalid code"` |
| 만료된 링크 | 7003 | `"Link has expired"` |
| 파일 미존재 | 7009 | `"File not found"` |
| 요청 한도 초과 | 4000 | `"Too many requests"` |

### 6.2 컴포넌트 레벨 에러 처리

| 컴포넌트 | 에러 처리 방식 |
|----------|----------------|
| `LinkInput.svelte` | `handleLinkSubmit` 호출을 `try/catch`로 감싸고, `err.message`를 UI에 표시 |
| `ImageViewer.svelte` | 개별 `getImageUrl` 호출을 `try/catch`로 감싸고 실패 시 `null` 반환, `filter(Boolean)`으로 제외 (조용한 실패) |
| `+page.svelte` | `fetchPublicLink` 에러는 `LinkInput`의 `try/catch`에서 처리됨 |

### 6.3 이미지 로딩 에러 (병렬 호출 패턴)

```javascript
// ImageViewer.svelte — 개별 실패를 허용하는 병렬 호출
const urls = await Promise.all(
  images.map(async (img) => {
    try {
      return await getImageUrl(code, img.fileid);
    } catch {
      return null;
    }
  })
);
imageUrls = urls.filter(Boolean);
```

| 단계 | 처리 방식 |
|------|-----------|
| 개별 이미지 URL 획득 실패 | `try/catch`에서 `null` 반환 — 해당 이미지만 건너뜀 |
| null 필터링 | `filter(Boolean)` — 유효한 URL만 렌더링 |
| 전체 실패 | 빈 배열 → 표시할 이미지 없음 |

### 6.4 네트워크 에러

`fetch` 자체가 실패하는 경우 (네트워크 단절 등)는 `ImageViewer`의 `try/catch` 블록에서 처리된다. 각 `getImageUrl` 호출을 감싸는 `try/catch`가 네트워크 에러도 포함하여 `null`로 흡수한다.

### 6.5 미비 사항

| 항목 | 현재 상태 |
|------|-----------|
| HTTP 상태 코드 검사 | 없음. `response.ok` 체크 없이 바로 `response.json()` 호출 |
| 타임아웃 | 없음. `fetch`에 타임아웃 설정 없음 |
| 응답 형식 검증 | 없음. `data.hosts[0]`, `data.path` 등 필드 존재 여부 미검증 |
