# 06. 데이터 스키마

## 1. 개요

PclToon은 **전통적인 데이터베이스를 사용하지 않는다.** 백엔드 서버, ORM, 마이그레이션 등 서버 측 저장소가 일체 존재하지 않는 정적 SPA(SvelteKit + adapter-static)이다.

데이터 계층은 다음 세 가지로 구성된다:

| 계층 | 저장 위치 | 용도 | 영속성 |
|------|-----------|------|--------|
| **외부 데이터 소스** | pCloud Public API | 폴더/파일 메타데이터, 이미지 다운로드 URL | 원격 (읽기 전용) |
| **클라이언트 저장소** | `localStorage` | 테마 설정, 스크롤 북마크 | 브라우저별 영속 |
| **인메모리 상태** | Svelte `$state` / `writable` | 현재 뷰 상태, 탐색 데이터 | 세션 한정 (새로고침 시 소멸) |

## 2. 외부 데이터 소스 (pCloud API)

앱이 사용하는 pCloud Public API 엔드포인트는 두 가지이다. 모든 호출은 클라이언트에서 직접 수행되며, 인증 없이 공개 링크 코드(`code`)만으로 접근한다.

### 2.1 showpublink 응답 구조

**엔드포인트:** `GET https://api.pcloud.com/showpublink?code={code}`

**호출 위치:** `src/lib/pcloud.js` > `fetchPublicLink()`

**용도:** 공개 링크의 루트 폴더 메타데이터 및 하위 항목(폴더/파일) 목록 조회

```
응답 (정상):
{
  result: 0,                        // 성공 코드
  metadata: {
    name: string,                   // 루트 폴더명
    contents: [                     // 하위 항목 배열
      {
        isfolder: boolean,          // true: 폴더, false: 파일
        name: string,               // 항목 이름
        fileid: number,             // 파일 고유 ID (이미지 다운로드 시 사용)
        folderid: number,           // 폴더 고유 ID (북마크 키 생성 시 사용)
        contents?: [...]            // 하위 폴더인 경우 재귀적 중첩
      }
    ]
  }
}

응답 (에러):
{
  result: number,                   // 에러 코드 (정수, 예: 2000, 7003)
  error: string                     // 에러 메시지 (문자열)
}
```

> 앱 코드에서는 `data.error`의 truthy 여부만 확인하여 에러를 판별한다. `error`는 문자열이며, `throw new Error(data.error)`로 전달된다.

**앱 내 사용 패턴:**

- `metadata.contents`에서 `isfolder === true`인 항목을 필터링하여 에피소드 폴더 목록 생성
- `isfolder === false`이면서 확장자가 이미지인 항목(`jpg`, `jpeg`, `png`, `gif`, `webp`, `bmp`)을 필터링하여 이미지 목록 생성
- 모든 목록은 `name` 기준 자연 정렬(`localeCompare`의 `numeric: true, sensitivity: 'base'` 옵션)

### 2.2 getpublinkdownload 응답 구조

**엔드포인트:** `GET https://api.pcloud.com/getpublinkdownload?code={code}&fileid={fileid}`

**호출 위치:** `src/lib/pcloud.js` > `getImageUrl()`

**용도:** 특정 파일의 CDN 다운로드 URL 획득

**요청 옵션:** `referrerPolicy: 'no-referrer'`

```
응답 (정상):
{
  result: 0,                        // 성공 코드
  hosts: string[],                  // CDN 호스트명 배열
  path: string                      // 파일 경로
}

응답 (에러):
{
  result: number,                   // 에러 코드 (정수, 예: 2000, 7009)
  error: string                     // 에러 메시지 (문자열)
}
```

> 앱 코드에서는 `data.error`의 truthy 여부만 확인하여 에러를 판별한다. `error`는 문자열이며, `throw new Error(data.error)`로 전달된다.

**최종 이미지 URL 조합:**

```
`https://${hosts[0]}${path}`
```

항상 `hosts` 배열의 첫 번째 요소(`hosts[0]`)를 사용한다.

## 3. 클라이언트 저장소 (localStorage)

`localStorage`에 저장되는 키는 두 종류이다.

### 3.1 theme

| 항목 | 값 |
|------|---|
| **키** | `theme` |
| **타입** | `string` |
| **가능한 값** | `"dark"` (다크 모드) \| `""` (빈 문자열, 라이트 모드) |
| **기본값** | 저장된 값이 없으면 `window.matchMedia('(prefers-color-scheme: dark)')` 결과에 따라 결정 |
| **읽기 시점** | 앱 마운트 시 (`+layout.svelte` > `onMount` > `theme.init()`) |
| **쓰기 시점** | 테마 토글 버튼 클릭 시 (`ThemeToggle.svelte` > `theme.toggle()`) |
| **관리 모듈** | `src/lib/stores/theme.js` > `createThemeStore()` |

### 3.2 bookmark_{code}_{folderId}

| 항목 | 값 |
|------|---|
| **키 패턴** | `bookmark_{code}_{folderId}` |
| **키 예시** | `bookmark_kZAbCdXZ0_12345678` |
| **타입** | `string` (정수를 문자열로 저장) |
| **값** | `window.scrollY` 값 (픽셀 단위 스크롤 위치) |
| **읽기 시점** | `ImageViewer` 마운트 시 (`onMount`), 이미지 URL 로딩 완료 후 저장된 위치로 스크롤 복원 |
| **쓰기 시점** | (1) `beforeunload` 이벤트 발생 시, (2) `ImageViewer` 언마운트 시 (`onMount` 반환 클린업 함수) |
| **쓰기 조건** | `folderId`가 truthy한 경우에만 저장 |
| **관리 모듈** | `src/lib/components/ImageViewer.svelte` > `savePosition()` |

**키 구성 요소:**

| 세그먼트 | 출처 | 설명 |
|----------|------|------|
| `code` | URL에서 추출한 pCloud 공개 링크 코드 | `extractCode()` 함수로 파싱 |
| `folderId` | `showpublink` 응답의 `folderid` 필드 | 현재 보고 있는 폴더의 고유 ID |

## 4. 인메모리 상태 모델

### 4.1 페이지 상태 (`src/routes/+page.svelte`)

Svelte 5의 `$state` 룬으로 관리되는 메인 페이지 상태이다.

| 변수명 | 타입 | 초기값 | 설명 |
|--------|------|--------|------|
| `currentView` | `string` | `'input'` | 현재 화면 모드. `'input'` \| `'list'` \| `'viewer'` |
| `code` | `string` | `''` | pCloud 공개 링크 코드 |
| `rootData` | `object \| null` | `null` | `fetchPublicLink()` 응답 전체 (최상위 메타데이터) |
| `currentFolder` | `object \| null` | `null` | 현재 선택된 폴더 객체 |
| `folders` | `array` | `[]` | 현재 표시 중인 하위 폴더 목록 |
| `images` | `array` | `[]` | 현재 표시 중인 이미지 파일 목록 |
| `breadcrumb` | `array` | `[]` | 탐색 경로 스택 (뒤로가기 구현용) |

**`currentView` 상태 전이:**

```
'input' ─── handleLinkSubmit() ───┬──→ 'viewer'  (이미지만 있는 경우)
                                  └──→ 'list'    (폴더가 있는 경우)

'list'  ─── handleFolderSelect() ─┬──→ 'viewer'  (이미지가 있는 경우)
                                  └──→ 'list'    (하위 폴더만 있는 경우)

'viewer' ── handleBack() ─────────→ 'list'    (상위에 폴더가 있는 경우)
'list'   ── handleBack() ─────────→ 'list'    (breadcrumb 남은 경우)
'list'   ── handleBack() ─────────→ 'input'   (breadcrumb 소진 시)
```

**`breadcrumb` 항목 구조:**

```
// 루트 레벨 (fetchPublicLink 응답)
{ name: string, data: object }      // data = fetchPublicLink() 전체 응답

// 하위 폴더 레벨
{ name: string, folder: object }    // folder = 선택된 폴더 객체
```

### 4.2 테마 상태 (`src/lib/stores/theme.js`)

Svelte `writable` 스토어로 관리된다.

| 변수명 | 타입 | 초기값 | 설명 |
|--------|------|--------|------|
| `theme` | `writable<string>` | `''` | `'dark'` 또는 `''` (라이트) |

**메서드:**

| 메서드 | 동작 |
|--------|------|
| `init()` | `localStorage`에서 읽거나, 없으면 시스템 다크모드 설정 확인 후 적용 |
| `toggle()` | `'dark'` <-> `''` 전환, `localStorage`에 저장 |
| `set(value)` | 직접 값 설정, `localStorage`에 저장 |

### 4.3 LinkInput 상태 (`src/lib/components/LinkInput.svelte`)

## 5. 데이터 관계도

```
┌─────────────────────────────────────────────────────────────┐
│                     pCloud Public API                        │
│                     (외부 데이터 소스)                         │
├─────────────────────────────┬───────────────────────────────┤
│  showpublink                │  getpublinkdownload           │
│  ┌─────────────────────┐    │  ┌──────────────────────┐     │
│  │ metadata             │    │  │ hosts: string[]      │     │
│  │  ├─ name             │    │  │ path: string         │     │
│  │  └─ contents[]       │    │  └──────────────────────┘     │
│  │      ├─ isfolder     │    │          │                    │
│  │      ├─ name         │    │          ▼                    │
│  │      ├─ fileid ──────┼────┤  https://{hosts[0]}{path}    │
│  │      ├─ folderid     │    │  (이미지 CDN URL)              │
│  │      └─ contents[]?  │    │                               │
│  └─────────────────────┘    │                               │
└──────────┬──────────────────┴───────────────────────────────┘
           │
           │ fetchPublicLink(code)
           ▼
┌─────────────────────────────────────────────────────────────┐
│                   인메모리 상태 (+page.svelte)                │
│                                                              │
│  rootData ◄── API 응답 전체                                   │
│      │                                                       │
│      ├──► folders[]  ◄── contents.filter(isfolder)           │
│      │        │                                              │
│      │        └──► handleFolderSelect() ──► folders/images   │
│      │                                        갱신            │
│      └──► images[]   ◄── contents.filter(!isfolder && 이미지) │
│               │                                              │
│               │  getImageUrl(code, fileid)                   │
│               ▼                                              │
│  ImageViewer.imageUrls[] ◄── CDN URL 목록                    │
│                                                              │
│  breadcrumb[] ◄── 탐색 경로 스택                               │
│  currentView  ◄── 'input' | 'list' | 'viewer'               │
│  code         ◄── URL에서 추출                                │
└──────────────────────┬──────────────────────────────────────┘
                       │
                       │ 읽기/쓰기
                       ▼
┌─────────────────────────────────────────────────────────────┐
│                   localStorage                               │
│                   (클라이언트 영속 저장소)                      │
│                                                              │
│  ┌─────────────────────────────────────────────────────┐     │
│  │ "theme"                                             │     │
│  │  값: "dark" | ""                                    │     │
│  │  용도: 다크/라이트 테마 설정 유지                      │     │
│  └─────────────────────────────────────────────────────┘     │
│                                                              │
│  ┌─────────────────────────────────────────────────────┐     │
│  │ "bookmark_{code}_{folderId}"                        │     │
│  │  값: scrollY 정수 (문자열)                           │     │
│  │  용도: 에피소드별 읽기 위치 복원                       │     │
│  └─────────────────────────────────────────────────────┘     │
└─────────────────────────────────────────────────────────────┘
```

**데이터 흐름 요약:**

1. 사용자가 pCloud 공개 링크를 입력하면 `code`를 추출한다
2. `showpublink` API로 폴더/파일 메타데이터를 가져와 인메모리 상태에 저장한다
3. 폴더 선택 시 해당 폴더의 `contents`를 파싱하여 하위 폴더/이미지 목록을 갱신한다
4. 이미지 뷰어 진입 시 각 `fileid`로 `getpublinkdownload` API를 호출하여 CDN URL을 획득한다
5. 스크롤 위치는 `localStorage`에 `bookmark_{code}_{folderId}` 키로 저장/복원된다
6. 테마 설정은 `localStorage`의 `theme` 키로 유지된다
